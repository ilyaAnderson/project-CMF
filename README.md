# CMF Store — учебный интернет-магазин

Адаптивный концепт витрины техники CMF by Nothing. Проект посвящён продуктовым карточкам, крупным промо-блокам и демонстрации вариантов устройств.

**Демо:** https://ilyaanderson.github.io/project-CMF/

## Что реализовано

- Полноэкранные промо-секции с каруселью
- Каталог устройств с описаниями и ценами
- Выбор цветового варианта устройств
- Отзывы и информационные блоки
- Стили для экранов до 1024, 768 и 480 пикселей
- HTML, CSS и JavaScript

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000
```

Затем перейдите на http://localhost:8000.

> Учебная витрина для демонстрации интерфейса. Корзина, оформление и оплата заказа не подключены.

# CMF Store — storefront concept

A responsive storefront concept for CMF by Nothing devices. It focuses on product cards, full-width campaign sections, and device color variants.

**Live demo:** https://ilyaanderson.github.io/project-CMF/

The page includes a promo carousel, product information, color selection, editorial sections, and breakpoints for tablet and mobile screens. It uses HTML, CSS, and JavaScript.

Run it locally with `python3 -m http.server 8000` from the project root, then open http://localhost:8000.

> This is a front-end demo. Cart, checkout, and payment flows are not connected.
