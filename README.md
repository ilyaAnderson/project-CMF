# CMF Store

Русскоязычная учебная витрина Buds Pro 2, Neckband Pro, Nothing Phone (3) и Watch Pro. Витрина, каталог и диалоги написаны на React и TypeScript. Three.js загружается при входе в обзор. Семь глав связаны с абсолютным прогрессом прокрутки и воспроизводятся в обратном направлении при прокрутке вверх.

Первый кадр побережья, подложки волны, общий план и режим кадров используют изображения из дизайн-пакета. Корпус Buds Pro 2, его шарнир и Smart Dial загружаются из GLB, экспортированного из Blender. Вкладыши, Neckband Pro, Phone (3) и Watch Pro собираются из геометрии Three.js. Внутренности вкладыша и часов показаны схематично. Числа на экранах часов демонстрационные.

## Запуск

```sh
npm ci
npm run typecheck
npm run build
npm run serve
```

Откройте [локальную витрину](http://localhost:8000/). GitHub Pages обслуживает корень репозитория, поэтому изменения в исходниках включают обновлённые `storefront.js` и `showcase.js`.

## Обновление модели кейса

Откройте `models/buds-pro-2.blend` в Blender. При экспорте выделите ветвь `BudsCase` и её дочерние объекты, сохраните файл как `material/cmf/buds-case.glb`. Сохраните имена узлов `LidHinge` и `SmartDial`: Three.js использует их для вычисления позы. Скрипт в репозитории пересоздаёт базовую Blender-сцену и соответствующий GLB.

```sh
blender -b --python scripts/build_case.py
```

В режиме уменьшенного движения и при недоступном WebGL доступен обзор в кадрах. Звук включается кнопкой в 3D-обзоре. Светло-серый вариант Neckband Pro использует [изображение Nothing](https://nothing.tech/products/cmf-neckband-pro?Color=Light+Grey).

Демонстрационная корзина хранится в этом браузере. Кнопка оформления показывает подтверждение демо; заказ и оплата не выполняются.
